Ternary Diagram Simulator

What this tool does:
  • Drag the point or type amounts to set a three component composition
  • Reads each component off its axis with live arrows and value boxes
  • Switches between fractions (0 to 1) and percentages (0 to 100 %)
  • Lets you rename the axes, recolor them, and map each to its own range
